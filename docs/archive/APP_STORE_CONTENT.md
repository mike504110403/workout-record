## 🎯 提交流程

### 步驟 1: 準備資料
- [ ] App 名稱和副標題
- [ ] 完整描述和推廣文字
- [ ] 關鍵字
- [ ] 截圖（3-5 張，6.7" 尺寸）
- [ ] 隱私權政策 URL

### 步驟 2: 在 App Store Connect 填寫
1. 登入 https://appstoreconnect.apple.com
2. 選擇「我的 App」
3. 選擇「WorkitOut」
4. 填寫「App 資訊」
5. 填寫「定價與供應狀況」
6. 填寫「App 隱私」
7. 準備版本發佈

### 步驟 3: 準備版本
1. 點擊「iOS App」→「準備提交」
2. 上傳截圖
3. 填寫版本更新說明
4. 選擇構建版本（從 TestFlight）
5. 填寫 App 審核資訊
6. 填寫出口合規性資訊

### 步驟 4: 提交審核
1. 檢查所有資訊
2. 點擊「提交以供審核」
3. 等待審核結果（通常 1-3 天）
