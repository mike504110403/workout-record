# 技術選型

## 後端技術棧

### 核心技術
- **語言**: Golang
- **Web 框架**: Gin
- **ORM**: GORM
- **資料庫**: PostgreSQL
- **API 風格**: RESTful API

### 套件與工具
- **golang-jwt**: JWT 處理
- **golang-migrate**: 資料庫遷移
- **validator**: 資料驗證
- **cors**: 跨域處理

### 身份驗證
- JWT Token
- OAuth2.0
  - Apple Sign In
  - Google Sign In

### 部署
- Docker
- 雲端服務 (AWS/GCP/Railway/Render - 待定)

---

## 前端技術棧 (iOS)

### 核心技術
- **語言**: Swift
- **UI 框架**: SwiftUI
- **最低支援版本**: iOS 16+

### 功能模組
- **圖表**: Swift Charts (iOS 16+)
- **網路層**: URLSession 或 Alamofire
- **本地資料**: CoreData 或 SwiftData (iOS 17+)
- **本地快取**: UserDefaults + CoreData

### 身份驗證
- Apple Sign In SDK
- Google Sign In SDK
