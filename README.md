# 💪 WorkoutRecord - 智能健身訓練記錄

一款專為健身愛好者打造的訓練記錄 App，提供完整的訓練追蹤、數據分析和目標管理功能。

## ✨ 核心特色

### 📊 智能數據分析
- **訓練容量趨勢**：可視化您的訓練量變化，支持按肌群篩選（胸、背、腿、肩、手臂、核心）
- **智能肌群推斷**：即使缺少動作關聯，也能通過動作名稱智能推斷肌群分類
- **個人記錄（PR）追蹤**：自動記錄並追蹤您的 1RM 進步
- **體重管理**：記錄體重變化，追蹤身體組成
- **多維度圖表**：時間範圍選擇（週、月、3月、年）

### 🎯 目標設定與追蹤
- **週訓練目標**：設定每週訓練次數，接收進度提醒
- **肌群容量目標**：為不同肌群設定訓練容量目標
- **智能鼓勵**：根據完成度提供個性化鼓勵訊息
- **進度可視化**：實時查看目標達成情況

### 📝 訓練管理
- **智能訓練流程**：有未完成動作時自動隱藏新增動作按鈕，確保訓練專注度
- **訓練模板**：預設或自定義訓練模板，快速開始訓練
- **實時記錄**：記錄每組訓練的重量、次數和 RPE
- **組間休息計時器**：確保充分恢復
- **訓練歷史**：列表或日曆視圖查看歷史記錄，正確顯示動作名稱
- **詳細統計**：每次訓練的容量分布、動作明細
- **便捷操作**：點擊頁面其他位置即可關閉彈窗和鍵盤

### 🏋️ 動作庫
- **67 個系統動作**：涵蓋主要訓練動作，包含詳細肌群和動作模式分類
  - 胸部：12 個動作（槓鈴臥推、啞鈴飛鳥等）
  - 背部：11 個動作（硬舉、引體向上、划船等）
  - 腿部：12 個動作（深蹲、腿推、弓步蹲等）
  - 肩部：10 個動作（肩推、側平舉等）
  - 手臂：11 個動作（彎舉、三頭下壓等）
  - 核心：10 個動作（捲腹、平板支撐等）
- **自定義動作**：創建專屬的訓練動作，支持詳細肌群選擇
- **智能搜尋**：即時搜尋，支援中英文、肌群模糊查詢
- **分類篩選**：按部位、器材類型快速查找動作

## 🛠 技術架構

### iOS 客戶端
- **語言**：Swift 5.9+
- **UI 框架**：SwiftUI
- **架構**：MVVM
- **數據持久化**：CoreData（本地優先）
- **圖表**：Swift Charts
- **最低版本**：iOS 17.0

### 數據存儲
- **本地存儲**：CoreData
- **存儲位置**：App 沙盒目錄
- **容量估算**：1年約 5-10 MB
- **數據模型**：
  - User（用戶）
  - Workout（訓練記錄）
  - WorkoutExercise（訓練動作，含 exerciseName 備用名稱）
  - WorkoutSet（訓練組）
  - Exercise（動作庫）
  - Template（訓練模板）
  - BodyWeight（體重記錄）
  - PersonalRecord（個人記錄）
  - UserGoal（用戶目標）
- **數據完整性**：支持動作名稱持久化，確保歷史記錄正確顯示

### 後端 API（規劃中）
- **語言**：Go 1.21+
- **框架**：Gin
- **ORM**：GORM
- **數據庫**：PostgreSQL
- **認證**：JWT
- **部署狀態**：未來作為付費雲端同步功能

## 🚀 快速開始

### 環境要求
- macOS 13.0+
- Xcode 15.0+
- iOS 17.0+ (Simulator 或真機)
- Apple Developer Account（真機測試需要，免費或付費皆可）

### 運行步驟

```bash
# 1. Clone 專案
git clone <repository-url>
cd workout-record

# 2. 進入 iOS 項目目錄
cd ios/WorkoutRecord

# 3. 打開 Xcode 項目
open WorkoutRecord.xcodeproj

# 4. 配置簽名（真機測試需要）
# - 在 Xcode 中選擇 WorkoutRecord target
# - 進入 Signing & Capabilities
# - 選擇你的 Team（Apple ID）

# 5. 選擇目標設備
# - Simulator：選擇任一 iOS 17+ 模擬器
# - 真機：連接 iPhone 並選擇，需啟用開發者模式

# 6. 運行
# - 按 ⌘R 或點擊 Run 按鈕
```

### 真機測試步驟
1. **連接 iPhone**：使用 USB 線連接至 Mac
2. **信任電腦**：iPhone 上點擊「信任此電腦」
3. **啟用開發者模式**：
   - iPhone：設定 → 隱私權與安全性 → 開發者模式 → 開啟
   - 重新啟動 iPhone
4. **配置簽名**：在 Xcode 選擇你的 Apple ID 作為 Team
5. **首次安裝**：需在 iPhone 信任開發者憑證
   - 設定 → 一般 → VPN 與裝置管理 → 信任你的 Apple ID
6. **運行 App**：可拔除 USB 線獨立使用

### 首次啟動

App 首次啟動時會自動：
1. 初始化 CoreData 資料庫
2. 創建默認用戶
3. 載入 67 個系統動作（含詳細肌群和動作模式分類）
4. 創建 5 個示例訓練模板：
   - PPL - Push (推)：胸、肩、三頭訓練
   - PPL - Pull (拉)：背、二頭訓練
   - PPL - Legs (腿)：腿部訓練
   - 上半身：綜合上肢訓練
   - 全身訓練：複合動作訓練

## 📊 數據存儲說明

### 本地存儲優勢
- ✅ **無需網絡**：完全離線可用
- ✅ **數據私密**：所有數據存儲在本地
- ✅ **快速訪問**：零延遲的數據讀寫
- ✅ **零成本**：無需服務器和數據庫費用

### 存儲空間估算
基於每天一次訓練，每次 10 個動作，每個動作 4 組：
- 1 個月：約 500 KB
- 6 個月：約 3 MB
- 1 年：約 5-10 MB
- 2 年：約 10-20 MB

### 數據遷移
如需重置資料庫：
1. 刪除 App 並重新安裝，或
2. 修改 `WorkoutRecordApp.swift` 中的 `currentModelVersion`
