# 訓練模板整合功能說明

## 📅 完成日期
2025-10-20

## ✅ 已實現的功能

### 1. 訓練模板概念
訓練模板 = 預先設定的訓練計劃，包含：
- 模板名稱和描述
- 一組預設動作
- 每個動作的建議組數和次數

### 2. 從訓練頁面選擇模板

**入口 1：訓練頁面**
1. 點擊底部「訓練」Tab
2. 看到兩個選項：
   - 「開始自由訓練」- 空白訓練，手動添加動作
   - **「從模板開始」** - 選擇模板快速開始

**流程**：
```
訓練頁面
  ↓ 點擊「從模板開始」
模板選擇器（Sheet）
  ├─ 系統模板（5個預設）
  │   ├─ PPL - Push（胸、肩、三頭）
  │   ├─ PPL - Pull（背、二頭）
  │   ├─ PPL - Legs（腿部）
  │   ├─ 上肢訓練
  │   └─ 全身訓練
  └─ 我的模板（用戶自建）
  ↓ 選擇模板
自動開始訓練
  ├─ 計時器啟動
  ├─ 自動添加模板中的所有動作
  └─ 可以開始記錄組數和重量
```

### 3. 從設定頁面使用模板

**入口 2：設定頁面**
1. 點擊底部「設定」Tab
2. 點擊「訓練模板」→「我的模板」
3. 看到所有可用模板
4. 點擊任意模板卡片的**「使用此模板」**按鈕

**流程**：
```
設定 → 我的模板
  ↓ 點擊「使用此模板」
自動切換到「訓練」Tab
  ↓ 0.3秒後
自動開始訓練（已載入模板中的動作）
```

### 4. 模板管理功能

**位置**：設定 → 訓練模板 → 我的模板

**功能**：
- ✅ 查看所有模板（系統 + 自建）
- ✅ 創建新模板
  - 輸入名稱和描述
  - 選擇多個動作
  - 保存
- ✅ 使用模板（自動跳轉到訓練頁面）
- ✅ 編輯模板（按鈕存在，功能待實現）
- ✅ 刪除自建模板

## 🎯 預設系統模板

### 1. PPL - Push（推）
- **描述**：胸、肩、三頭訓練
- **動作**：
  - 槓鈴臥推（4組 × 8次）
  - 上斜啞鈴臥推（4組 × 10次）
  - 肩推（4組 × 10次）
  - 側平舉（3組 × 12次）
  - 三頭下壓（3組 × 12次）

### 2. PPL - Pull（拉）
- **描述**：背、二頭訓練
- **動作**：
  - 硬舉（3組 × 5次）
  - 引體向上（4組 × 8次）
  - 槓鈴划船（4組 × 10次）
  - 坐姿划船（3組 × 12次）
  - 槓鈴彎舉（3組 × 10次）

### 3. PPL - Legs（腿）
- **描述**：腿部完整訓練
- **動作**：
  - 深蹲（4組 × 8次）
  - 羅馬尼亞硬舉（4組 × 10次）
  - 腿推機（4組 × 12次）
  - 腿彎舉（3組 × 12次）
  - 提踵（4組 × 15次）

### 4. 上肢訓練
- **描述**：上半身完整訓練
- **動作**：
  - 臥推（4組 × 8次）
  - 划船（4組 × 10次）
  - 肩推（3組 × 10次）
  - 二頭彎舉（3組 × 12次）
  - 三頭下壓（3組 × 12次）

### 5. 全身訓練
- **描述**：適合初學者的全身訓練
- **動作**：
  - 深蹲（3組 × 10次）
  - 臥推（3組 × 10次）
  - 硬舉（3組 × 8次）
  - 引體向上（3組 × 8次）
  - 肩推（3組 × 10次）

## 🔧 技術實現

### 1. WorkoutViewModel 新增方法
```swift
func startWorkoutFromTemplate(_ template: TemplateInfo)
```
- 開始訓練
- 啟動計時器
- 自動添加模板中的所有動作（不含組數，需用戶記錄）

### 2. WorkoutView 新增組件
- `TemplatePickerSheet` - 模板選擇器
- `TemplatePickerCard` - 模板卡片
- 支持通過 binding 接收外部 viewModel

### 3. 跨 Tab 導航（通知機制）
- 使用 `NotificationCenter` 傳遞模板選擇事件
- `MainTabView` 監聽通知
- 自動切換到訓練 Tab
- 延遲 0.3 秒後啟動訓練（確保 Tab 切換完成）

## 📱 使用場景

### 場景 1：快速開始常規訓練
```
用戶打開 App → 點擊「訓練」→ 點擊「從模板開始」
→ 選擇「PPL - Push」→ 開始記錄臥推的重量和次數
```

### 場景 2：瀏覽模板後決定訓練
```
用戶打開 App → 點擊「設定」→ 點擊「我的模板」
→ 瀏覽可用模板 → 點擊「PPL - Legs」的「使用此模板」
→ 自動跳轉到訓練頁面 → 開始記錄深蹲
```

### 場景 3：創建自定義模板
```
設定 → 我的模板 → 點擊「+」→ 輸入「胸背超級組」
→ 添加動作：臥推、划船、上斜臥推、引體向上
→ 保存 → 下次可以直接使用
```
