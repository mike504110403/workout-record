## 📊 新增的數據結構

### Exercise 模型擴展

```swift
struct Exercise {
    // 新增屬性
    var primaryMuscleGroup: PrimaryMuscleGroup  // 主要肌群
    var movementPattern: MovementPattern        // 動作模式
    
    enum PrimaryMuscleGroup {
        case chest      // 胸
        case back       // 背
        case legs       // 腿
        case shoulders  // 肩
        case arms       // 手臂
        case core       // 核心
        case glutes     // 臀部
        case fullBody   // 全身
    }
    
    enum MovementPattern {
        case push       // 推（臥推、肩推、三頭等）
        case pull       // 拉（划船、引體、彎舉等）
        case squat      // 蹲（深蹲、腿推等）
        case hinge      // 髖鉸鏈（硬舉、羅馬尼亞硬舉等）
        case carry      // 負重行走（農夫走等）
        case rotation   // 旋轉（俄羅斯轉體等）
        case isolation  // 孤立（飛鳥、腿屈伸等）
    }
}
```

## 💾 本地存儲規格

### UserDefaults 存儲鍵
- `customExercises` - 存儲所有自定義動作
- `exerciseFavorites` - 存儲收藏的動作ID
- `exerciseHistory` - 存儲最近使用的動作

### 數據格式
```json
{
  "customExercises": [
    {
      "id": "uuid",
      "name": "史密斯臥推",
      "type": "machine",
      "primaryMuscleGroup": "chest",
      "movementPattern": "push",
      "description": "使用史密斯機進行臥推",
      "createdAt": "2025-10-20T10:00:00Z",
      "updatedAt": "2025-10-20T10:00:00Z"
    }
  ]
}
```
